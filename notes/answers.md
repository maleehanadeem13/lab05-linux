# Notes: /bin, /usr/bin and /usr/local/bin

/usr/bin is the main folder where most Linux commands live, like ls, git and python3.
These programs are installed and updated by Ubuntu itself.
/bin is not a real folder anymore. It is only a shortcut (symbolic link) to /usr/bin, kept so that old programs still work.
/usr/local/bin is for programs that I install by hand myself.
It is kept separate so that Ubuntu updates do not overwrite my own programs.
